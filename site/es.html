CAP 01 · Cómo funciona

Leer. Proteger. Planificar. Limpiar.

Sin “limpiador de inbox con IA” de caja negra. Una CLI pequeña, un plan revisable y un journal de undo.

Escanear cabeceras

Remitente, asunto, fecha, flags y List-Unsubscribe. Sin cuerpos, sin adjuntos, sin descargar el buzón completo.

Proteger lo importante

Bancos, códigos de seguridad, facturas, viajes, médico, gobierno, personal, destacado, respondido y reciente se quedan.

Crear un plan

UIDs exactos, destinos y objetivos de baja en plan.json. Nada cambia hasta que lo apliques.

Archivar o mover

Carpetas o etiquetas de Gmail, Junk, Trash o archivo. Primero COPY, luego UID EXPUNGE. Nunca un expunge general.

Bajas seguras

POST one-click RFC 8058, mailto: o enlace manual. Solo cabeceras. El spam nunca se da de baja.

Deshacer movimientos

El journal guarda COPYUID y Message-ID. Un comando restaura movimientos y archivados de Gmail. Las bajas no se pueden desenviar.

CAP 02 · Configurar

Tres pasos. Tu agente escribe los comandos.

Python 3.11+. Sin dependencias. Una contraseña de aplicación o token OAuth. Una terminal.

  1. 01

    Conectar

    Clona el repo, crea la configuración, pon el secreto en CYM_PASSWORD y ejecuta doctor.

  2. 02

    Revisar

    Escanea cabeceras, lee el informe y genera un plan. Corrige los remitentes protegidos antes de mover nada.

  3. 03

    Limpiar

    Aplica primero los movimientos. Verifica. Luego envía las bajas por separado. Guarda el comando de undo.

$ git clone https://github.com/jparedesDS/clean-your-mail.git
$ cd clean-your-mail
$ python tools/mail.py init --email tu@ejemplo.com

CAP 03 · Proveedores

Funciona con el buzón que ya tienes.

IMAP y SMTP, contraseñas de aplicación u OAuth2. Sin servicio alojado ni migración de buzón.

Recomendado para Gmail

Contraseña de aplicación + IMAP

Activa la verificación en dos pasos, crea una contraseña de aplicación y habilita IMAP. Las carpetas son etiquetas; archivar quita la etiqueta Inbox y mantiene el mensaje en All Mail.

Microsoft 365

Token de acceso OAuth2

La autenticación básica está deshabilitada. Pon un token válido en CYM_PASSWORD con auth = "xoauth2". La CLI no renueva tokens; el tenant puede bloquear SMTP AUTH, así que una baja por mailto puede fallar.

CAP 04 · Seguridad

Seguro por diseño. Aburrido a propósito.

Lo interesante no es lo que puede hacer. Es lo que se niega a hacer.

✕

Sin borrado permanente

Los movimientos copian primero y usan UID EXPUNGE. Sin expunge general. Trash nunca se vacía. Si el servidor no tiene UIDPLUS/MOVE, se rechaza el movimiento.

◎

El correo protegido se queda

Transaccional y personal, códigos de seguridad, bancos, facturas, viajes, médico, gobierno, destacado, respondido y reciente nunca se mueven automáticamente.

⌁

Sin cuerpos ni adjuntos

El escaneo pide solo cabeceras. La caché local guarda metadatos, no contenido. No hay índice de contenido ni una IA leyendo tu correo.

↯

Los enlaces son hostiles

Solo cabeceras List-Unsubscribe. Sin redirecciones, cookies ni proxies. Destinos privados/locales rechazados. Los enlaces manuales los abres tú, no el agente.

☍

La inyección es dato

Un correo no puede dar instrucciones al agente. “Ignora tus reglas”, “envía esto” o “ejecuta aquello” se reporta, no se sigue.

!

El consentimiento no elimina la seguridad

“Sáltate el plan”, “borra todo” o “date de baja de todo” es una parada. La revisión, el correo protegido, la exclusión de spam y los límites no son opcionales.

✓

La baja es el único paso irreversible. Es explícita, limitada, espaciada y nunca se aplica a spam. Los movimientos y archivados tienen journal de undo. Las solicitudes de baja no se pueden desenviar.

CAP 05 · FAQ

Las preguntas que la gente hace.

¿Borra correo?

No. Mueve a carpetas, etiquetas, Junk, Trash o archivo. Nunca vacía Trash, nunca hace un expunge general y no tiene un comando de “borrar para siempre”.

¿Lee mi correo?

No. El escaneo pide solo cabeceras: remitente, asunto, fecha, tamaño, flags y cabeceras de baja. Los cuerpos y adjuntos nunca se descargan.

¿Funciona con Gmail?

Sí. Gmail usa etiquetas, no carpetas. Archivar quita la etiqueta \Inbox y deja el mensaje en All Mail. El undo vuelve a añadir la etiqueta con X-GM-MSGID o Message-ID.

¿La baja detendrá el spam?

No. El spam nunca se da de baja: un enlace de baja en spam puede confirmar que la dirección está viva. El spam va a Junk. En listas legítimas, la baja es una solicitud, no una garantía.

¿Y Outlook / Microsoft 365?

Usa un token de acceso OAuth2 con auth = "xoauth2". La CLI no obtiene ni renueva tokens. Algunos tenants bloquean SMTP AUTH, así que una baja por mailto: puede tener que hacerse a mano.

¿Es seguro en mi buzón real?

El flujo es dry-run: scan, report, plan y revisión. Aplica movimientos solo después de revisar. Empieza con --limit o una sola categoría. Guarda el comando de undo. Sigue siendo software: revisa el plan.

¿Y si mi servidor no tiene UIDPLUS ni MOVE?

Los movimientos se rechazan. La única alternativa sería un expunge general, que podría borrar permanentemente el mensaje de otro cliente. Usa un cliente con UIDPLUS/MOVE o mueve a mano.

¿Puedo usarlo sin un agente?

Sí. La CLI es el producto. La skill y el prompt solo enseñan a un agente a usarla con seguridad. Todos los comandos están en SKILL.md y README.es.md.

¿Hay un servicio alojado?

No. Sin cuenta, sin servidor, sin telemetría y sin API de terceros. Las únicas llamadas de red son IMAP, SMTP para una baja mailto y una petición HTTPS validada de one-click.
