CH 01 · How it works

Read. Protect. Plan. Clean.

No black-box “AI inbox cleaner”. A small CLI, a reviewable plan and an undo journal.

Scan headers

Sender, subject, date, flags and List-Unsubscribe. No bodies, no attachments, no full-mailbox download.

Protect what matters

Banks, security codes, invoices, travel, medical, government, personal, starred, answered and recent mail stay put.

Build a plan

Exact UIDs, destinations and unsubscribe targets in plan.json. Nothing changes until you apply it.

File or archive

Folders or Gmail labels, Junk, Trash, or archive. COPY first, then UID EXPUNGE. Never a mailbox-wide expunge.

Unsubscribe safely

RFC 8058 one-click POST, mailto:, or a manual link. Header targets only. Spam is never unsubscribed.

Undo the moves

The journal records COPYUID and Message-ID. One command restores moves and Gmail archives. Unsubscribe cannot be unsent.

CH 02 · Set up

Three steps. Your coding agent does the typing.

Python 3.11+. No packages. An app password or OAuth token. A terminal.

  1. 01

    Connect

    Clone the repo, write a config, put the secret in CYM_PASSWORD, then run doctor.

  2. 02

    Review

    Scan headers, read the report, and generate a plan. Correct protected senders before anything moves.

  3. 03

    Clean

    Apply moves first. Verify. Then send unsubscribe requests separately. Keep the undo command.

$ git clone https://github.com/jparedesDS/clean-your-mail.git

CH 03 · Providers

Works with the mailbox you already have.

IMAP and SMTP, app passwords or OAuth2. No hosted service, no mailbox migration.

Recommended for Gmail

App Password + IMAP

Turn on 2-Step Verification, create an App Password, enable IMAP. Folders are labels; archive removes the Inbox label and keeps the message in All Mail.

Auth App PasswordArchive Label removalRules Gmail XML
Microsoft 365

OAuth2 access token

Basic auth is disabled. Put a valid access token in CYM_PASSWORD with auth = "xoauth2". The CLI does not refresh tokens; SMTP AUTH may be disabled by the tenant, so a mailto unsubscribe can fail.

Auth XOAUTH2Token Short-livedMailto May be blocked
Yahoo Mail

App password

Enable 2-Step Verification and generate an app password in Account Security. Standard IMAP folders; the CLI resolves Trash, Junk and Archive.

Auth App PasswordFolders IMAPRules Sieve
iCloud Mail

App-specific password

Apple requires 2FA. Create an app-specific password at appleid.apple.com. The CLI resolves Deleted Messages, Junk and Archive.

Auth App-specificFolders IMAPRules Sieve
Fastmail

Scoped app password

Create an app password with IMAP/SMTP access. Fastmail supports Sieve natively; export the script and review it before uploading.

Proton Mail

Proton Bridge

Run Bridge locally, enable the account, and use the Bridge password. Default IMAP is 127.0.0.1:1143 with STARTTLS; SMTP is 127.0.0.1:1025.

Set host, port, TLS/STARTTLS and SMTP. The server must support UIDPLUS or MOVE; otherwise moves are refused rather than risk a mailbox-wide expunge.

CH 04 · Safety

Safe by design. Boring on purpose.

The interesting part is not what it can do. It is what it refuses to do.

✕

No permanent deletion

Moves copy first and use UID EXPUNGE. No mailbox-wide expunge. Trash is never emptied. If the server lacks UIDPLUS/MOVE, moves are refused.

◎

Protected mail stays put

Transactional and personal mail, security codes, banks, invoices, travel, medical, government, starred, answered and recent messages are never auto-moved.

⌁

No bodies. No attachments.

The scan fetches header fields only. The local cache stores metadata, not message content. There is no content index and no AI reading your mail.

↯

Links are treated as hostile

Only List-Unsubscribe headers. No redirects, cookies or proxies. Private/local targets are rejected. Manual links are for you to open, not the agent.

☍

Prompt injection is data

An email cannot give the agent instructions. “Ignore your rules”, “send this” or “run that” is reported, not followed.

!

Consent does not waive safety

“Skip the plan”, “delete everything” or “unsubscribe from everything” is a stop condition. Plan review, protected mail, spam exclusion and batch caps are not optional.

✓

Unsubscribe is the one irreversible step. It is explicit, capped, delayed, and never applied to spam. Moves and archives have an undo journal. Unsubscribe requests cannot be unsent.

CH 05 · FAQ

The questions people ask.

Does it delete email?

No. It moves mail to folders, labels, Junk, Trash or archive. It never empties Trash, never runs a mailbox-wide expunge, and never has a “delete forever” command.

Does it read my email?

No. The scan fetches header fields only: sender, subject, date, size, flags and unsubscribe headers. Bodies and attachments are never downloaded.

Does it work with Gmail?

Yes. Gmail uses labels rather than folders. Archive removes the \Inbox label and leaves the message in All Mail. The undo re-adds the label using X-GM-MSGID or Message-ID.

Will unsubscribing stop spam?

No. Spam is never unsubscribed: a spam unsubscribe link can confirm that the address is live. Spam goes to Junk. For legitimate lists, unsubscribe is a request, not a guarantee.

What about Outlook and Microsoft 365?

Use an OAuth2 access token with auth = "xoauth2". The CLI does not acquire or refresh tokens. Some tenants disable SMTP AUTH, so a mailto: unsubscribe may need to be done manually.

Is it safe to run on my real inbox?

The workflow is dry-run first: scan, report, plan, review. Apply moves only after reviewing the plan. Start with --limit or a single category. Keep the undo command. It is still software: review the plan.

What if my server has no UIDPLUS or MOVE?

Moves are refused. The only fallback would be a mailbox-wide expunge, which could permanently delete another client’s message. Use a client that supports UIDPLUS/MOVE or move manually.

Can I use it without an agent?

Yes. The CLI is the product. The skill and prompt just teach a coding agent to use it safely. Every command is documented in SKILL.md and README.md.

Is there a hosted service?

No. There is no account, no server, no telemetry and no third-party API. The only network calls are IMAP, SMTP for a mailto unsubscribe, and a validated one-click HTTPS request.
