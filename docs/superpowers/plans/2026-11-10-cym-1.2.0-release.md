# CleanYourMail 1.2.0 Validated Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Validate Gmail and Outlook/Microsoft 365 with real accounts, record the results, and publish CleanYourMail 1.2.0.

**Architecture:** Use the existing `tools/mail.py` against dedicated accounts, seed synthetic old newsletter messages so `plan` and `apply` have safe targets, verify `undo`, then bump the version and update the static website metadata. No product code changes are expected unless a real provider exposes a bug.

**Tech Stack:** Python 3.11+ (standard library), PowerShell on Windows, GitHub CLI, static HTML/CSS.

**Spec:** `docs/superpowers/specs/2026-11-10-cym-1.2.0-release-design.md`

## Global Constraints

- Use dedicated test accounts. Never run the first write test on a production mailbox.
- No passwords, OAuth tokens, real addresses or Message-IDs in the chat, repo, issues, logs or
  screenshots.
- `apply` uses `--limit 5` and the exact `httpbin.org` group key from the plan. `undo` is verified
  before any unsubscribe.
- `unsubscribe` uses `--limit 1`, a synthetic public target, and is tested last.
- No permanent deletion; headers only; protected mail stays protected.
- CI must stay green on Windows, macOS and Linux.
- The release is blocked if `doctor`, `apply` or `undo` fails for Gmail or Outlook.
- A provider may be `partial` only when `unsubscribe` or `rules` was not exercised; say so in the
  validation table and the release notes.

## Review Focus

1. **Wrong messages moved.** A real mailbox plan may contain real senders. Confirm a group key
   containing `httpbin.org` is present and always pass that exact key to `--group`; if it is
   missing, stop. Never apply without the group filter.
2. **Undo does not restore.** After every apply, verify the seeded messages are back in INBOX before
   continuing. A failed undo blocks the release.
3. **Microsoft code expiry.** `connect --wait` must run with at least a 15-minute timeout, or in the
   background. If the code expires, restart with `--no-wait`.
4. **Website version/CSP drift.** Changing `softwareVersion` requires recomputing the JSON-LD hash;
   the web test must pass and the live page must load without a CSP error.
5. **Gmail archive undo.** Archive is a label removal, not a folder move. Verify the `\Inbox` label
   returns after `undo`; a folder-only pass is not enough.

## Task 2: Seed safe test messages

**Files:**

**Interfaces:**

- [ ] **Step 1: Write the seed script**

Create `$env:TEMP\cym-seed.py`:

```python
import argparse
import datetime as dt
import imaplib
import sys
from email.message import EmailMessage

sys.path.insert(0, r"C:\Users\xht\Desktop\cleanyourmail\tools")
from config import load_config, resolve_secret
from imap import MailClient

parser = argparse.ArgumentParser()
parser.add_argument("--config", required=True)
parser.add_argument("--count", type=int, default=3)
args = parser.parse_args()

config = load_config(args.config)
secret = resolve_secret(config.account)
client = MailClient(config.account, secret, verbose=False).connect()
try:
    for index in range(args.count):
        sent_at = dt.datetime.now(dt.timezone.utc) - dt.timedelta(days=60 + index)
        message = EmailMessage()
        message["From"] = "news@httpbin.org"
        message["To"] = config.account.email
        message["Subject"] = f"Weekly test newsletter {index + 1}"
        message["Date"] = sent_at.strftime("%a, %d %b %Y %H:%M:%S +0000")
        message["Message-ID"] = f"<cym-seed-{index + 1}@example.invalid>"
        message["List-Unsubscribe"] = "<https://httpbin.org/post>"
        message["List-Unsubscribe-Post"] = "List-Unsubscribe=One-Click"
        message.set_content("Synthetic CleanYourMail validation message.")
        status, data = client.connection.append(
            "INBOX", None, imaplib.Time2Internaldate(sent_at), message.as_bytes(),
        )
        print(index + 1, status, data)
finally:
    client.close()
```

- [ ] **Step 1: Update the JSON-LD version**

- [ ] **Step 2: Recompute the CSP hash**

Create `$env:TEMP\cym-csp.py`:

```python
import base64
import hashlib
import pathlib
import re

for name in ("index.html", "es.html"):
    path = pathlib.Path(name)
    text = path.read_text(encoding="utf-8")
    block = re.search(r'<script type="application/ld\+json">(.*?)</script>', text, re.S)
    digest = base64.b64encode(hashlib.sha256(block.group(1).encode("utf-8")).digest()).decode()
    text = re.sub(r"'sha256-[^']+'", f"'sha256-{digest}'", text, count=1)
    path.write_text(text, encoding="utf-8", newline="")
    print(name, digest)
```

Run it from the web repository:

```powershell

```
