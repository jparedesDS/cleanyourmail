# CleanYourMail — Family Brand Cheat Sheet

**Final decision: Return Fold in the CleanYourPhone family palette.** The mark is a lavender envelope with a gold return arrow on a carbon tile. “CleanYour” stays off-white and “Mail” is lavender. Full specifications live in [`brand/final-family/README.md`](../brand/final-family/README.md).

## Identity essentials

- **Name:** `CleanYourMail` (capital **C**, **Y**, **M**).
- **One-liner:** CleanYourMail is a local-first IMAP cleanup product: a Python CLI and agent skill today, with a desktop app in development. It reads headers only, plans before action, and gives every move a way back.
- **Taglines:** **Your inbox, minus the noise.** · **Tu bandeja, sin el ruido.**
- **Family idea:** **Control, not magic.**

## Palette and roles

- **Carbon `#15161A`:** background and logo tile.
- **Gold `#E2C15C`:** primary action, plan, CTA and return arrow (**10.34:1** on carbon).
- **Lavender `#A78BFA`:** envelope outline, links, journal and undo (**6.64:1** on carbon).
- **Lavender bright `#C4B5FD`:** “Mail” wordmark accent (**9.79:1** on carbon).
- **Coral `#D97A5E`:** only the irreversible unsubscribe warning (**5.94:1** on carbon).
- **Text `#ECE9E2`**, **muted `#A8A39B`**, **muted-2 `#8E8A82`**, **panel `#1C1E24`**, **panel-2 `#23252D`**.

## Logo and wordmark

- Dark rounded-square tile, lavender envelope, gold return arrow.
- No solid gold tile, no sparkle, no three-stripe ribbon.
- Favicon and app icon use the same lavender/gold split.
- Wordmark: `CleanYour` in `#ECE9E2`, `Mail` in `#C4B5FD`.
- Clear space: 25% of the visible tile width.
- Minimum sizes: 16 px favicon, 24 px symbol, 160 px lockup, 120 px wordmark.

## Do / Don't

- **Do** use gold for plan/primary action and lavender for undo/links.
- **Do** reserve coral for the irreversible unsubscribe state.
- **Do** say **headers only** and **reversible moves**, never “no email data at all” or “everything is reversible”.
- **Don't** use old green/purple Spectrum colors or the Forest/Lime palette as the primary.
- **Don't** use gradients, glows, robots, shields, sparkles or fake social proof.
- **Don't** imply the desktop app is already shipped; it is in development.
